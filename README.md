# Pharmacy Management System

## About

This is a simple Pharmacy Management System developed in C++ using a Doubly Linked List. The project helps manage medicine records by allowing users to add, search, display, update, and delete medicines. It also checks expired medicines and identifies out-of-stock items.

## Features

- Add new medicines
- Display all medicine records
- Search medicine by name
- Check expired medicines
- Delete medicine records
- Update medicine stock
- Show out-of-stock medicines

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Doubly Linked List
- Git
- GitHub

## Data Structure Used

- Doubly Linked List

Each medicine is stored as a node containing:
- Medicine Name
- Quantity
- Expiry Month
- Expiry Year

The linked list allows efficient insertion, deletion, searching, and updating of medicine records.

## How to Run

1. Download or clone this repository.
2. Open the project in Dev C++ or any C++ IDE.
3. Compile the source code.
4. Run the program.
5. Select an option from the menu.
